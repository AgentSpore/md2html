# MD2HTML

Zero-dependency Markdown to HTML converter. Single-file CLI tool in Python.

## Usage

```bash
# From file
python md2html.py input.md > output.html

# From stdin
cat input.md | python md2html.py > output.html
```

## Features

- Headers (h1-h6)
- Lists
- Code blocks
- Links and images
- Bold/italic
- Blockquotes
- Horizontal rules
- Clean HTML output with built-in styling
